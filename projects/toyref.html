ToyRef

Project Type

Windows Reference Tool

Role

Creator & Director

Date

September 2026 — ongoing

Location

Sydney NSW Australia

AI Use

Programming

A borderless-window media referencing tool. Each reference item acts like an independent sticky note, inspired by the way I used to collage things and draw in my physical art journal. Currently, it is a working prototype for Windows and under active development.

Background

Why ToyRef?

During my animation degree, I had tried multiple different image referencing applications, the likes of PureRef, BeeRef, even default image viewers, etc. However, in the end, I noticed I just started dumping random references directly into the working art software, like Photoshop. The benefits of such referencing apps were clear: we won’t inflate the file size of our working art save files. But I was puzzled by why simple solutions like PureRef did not feel very natural to use for me. Which brings me to finally designing ToyRef. With the help and capabilities of AI for programming, I am able to test and rapidly develop the prototype.

Workflow

Built around how I draw

I designed ToyRef around how I normally draw and work. I pinned down the actions I tend to do with reference images when drawing, like dropping opacity, resizing, putting them into a cluster, then pulling one out when needed, hiding them, etc. I built the features and controls around my habits to support them.

Interaction

Drawing through references

References by default are always on top, and they can be locked in place or hidden. Most reference apps stop there. However, I added a feature to allow clicking through the reference, to draw and interact with things directly underneath it.

Continued development

What’s next

Currently, ToyRef is already a substantially feature-rich working prototype. I am using it actively for various art and design works. The upcoming feature under development will be the colour tools, dragging a colour palette card directly out of a reference, which then can be placed directly into any art software. Eventually, ToyRef will be turned into a properly built app, maybe with cross-platform support for macOS.
